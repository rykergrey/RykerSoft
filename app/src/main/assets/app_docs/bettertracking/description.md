# bettertracking

Track food, supplements, exercise, measurements, lifestyle, and notes in one journal — featuring an adaptive calorie engine, AI logging and coaching, reminders, and cloud sync that works offline.

## Key Features
- **Six-Domain Journal**: Log Food, Supplement, Exercise, Measurement, Lifestyle, and Notes seamlessly.
- **Adaptive Calorie Engine**: Dynamic target adjustments based on weight trends (Mifflin–St Jeor + Energy Bank).
- **AI Quick Logging**: Snap photos or type natural language to log meals and calculate nutrition estimates.
- **Health Coach & Reports**: AI-driven analysis of daily, weekly, and monthly lifestyle trends.
