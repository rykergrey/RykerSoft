# INFORMANT

INFORMANT is a local workspace for researching YouTube videos, articles, and Reddit posts. Organize your research into projects, maintain notes and bookmarks on each item, and run AI chat or analysis against your collected material.

## Key Features
- **Project Workspaces**: Create, search, sort, rename, export, and import research projects.
- **Multi-Source Link Importer**: Batch import YouTube links, articles, and Reddit posts.
- **Interactive Player & Readers**: Built-in YouTube player with PiP, article reader, and Reddit thread reader.
- **AI Analysis Engine**: Summary generation, key takeaway extraction, mind maps, and context-aware chat.
