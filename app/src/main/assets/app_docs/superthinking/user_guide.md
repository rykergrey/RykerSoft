## 1. Workspace Structure
Organize your ideas into **Cards** stored within **Categories**. View cards in List, Grid, or Kanban board layouts.

## 2. Working with Cards & Tabs
Each Card can hold multiple tabs:
- **TEXT**: Markdown editor with live preview, song sheet transposition, and Mermaid/Markmap rendering.
- **CHAT**: Dedicated AI assistant chat tab with custom model parameters and context references.
- **IMAGE**: Upload images, execute OCR text extraction, or run image-to-text AI actions.
- **AUDIO**: Record voice notes, edit waveforms, and link audio segments directly into text.
- **VIDEO**: Store video files or YouTube URLs for transcription and note-taking.

## 3. AI Actions & Automation
Select any text or tab and choose an **AI Action** (Summarize, Mind Map, Grammar Fix, Action Builder) to process content instantly.

## 4. Songs & Linked Audio
Write chord sheets using `{C}` chord tokens. Transpose song keys on the fly, enable teleprompter auto-scroll, and link recorded audio clips directly to song sections.

## 5. Speech & Transcription
Use the built-in dictation mic or import audio/video files to generate fast, accurate speech transcriptions powered by Groq Whisper or Gemini.
