# SuperThink.ing

SuperThink.ing is a multimodal knowledge workspace built around cards and tabs for text, chat, image, audio, and video. Transform content with reusable AI actions, write song sheets with transposition, link audio into lyrics, transcribe speech, and work locally or sync across devices.

## Key Features
- **Multimodal Cards & Tabs**: Combine Text, Chat, Image, Audio, and Video tabs inside unified knowledge cards.
- **Reusable AI Action Engine**: Transform, summarize, generate, OCR, transcribe, and execute custom JS code.
- **Song Sheets & Linked Audio**: Transpose chords, link audio clips to lyrics, and auto-scroll teleprompter view.
- **Speech & Transcription**: High-accuracy STT via Groq Whisper, OpenAI, or Gemini for videos, YouTube, and voice notes.
